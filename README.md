# WordFission

A static dictionary website inspired by a modern landing page design. It uses the free Dictionary API to fetch word definitions, pronunciations, and example usage.

## Files

- `index.html` — page structure and layout
- `styles.css` — styling for hero, search panel, and result cards
- `script.js` — fetches dictionary data and renders results

## Run locally

1. Open `index.html` in your browser.
2. Or use a static server like `Live Server` in VS Code.

## Notes

- This site uses `https://api.dictionaryapi.dev` for word lookups.
- Works best when served from a local server or hosted static site.
